## Bug #1: Compound Multiplication (Coordination Collapse)

### Severity: CRITICAL
**Impact:** Coordination capacity collapsed to ~0 in 4/5 Monte Carlo runs (should retain 5-10% floor per research)

### Root Cause
**File:** `src/simulation/engine/phases/InformationEcologyPhase.ts:84-87`

Compound multiplication bug - phase was multiplying already-modified coordination by modifier each month:

```typescript
const baseCoordination = society.coordinationCapacity ?? 0.5;  // Line 84
society.coordinationCapacity = assertFinite(baseCoordination * coordinationModifier, {  // Line 87
```

**Result:** Exponential decay without floor
- Month 0: 0.65 (initial)
- Month 10: 0.65 × (0.7^10) = 0.018
- Month 20: 0.65 × (0.7^20) = 0.000005 (effectively zero)

### Fix
**Commits:** 28ec08ff, fcb36616

Added `baseCoordinationCapacity` field to society state (similar to `baselineCarryingCapacity` pattern):

**Changes:**
1. `src/types/game.ts` - Added `baseCoordinationCapacity: number` to Society interface
2. `src/simulation/initialization.ts` - Initialize to 0.65 (same as initial coordinationCapacity)
3. `src/simulation/engine/phases/InformationEcologyPhase.ts` - Use base value instead of accumulated value

**Pattern followed:** Regional populations `carryingCapacity` calculation (src/simulation/regionalPopulations.ts:809)

### Validation
After fix:
- Coordination floor restored (minimum observed: ~0.05 in collapse scenarios)
- Monte Carlo determinism maintained (CV < 0.01%)
- Research-consistent degradation (20-40% drop during crises, not 99.99%)

## Bug #2: 1-Month Shock Timing Lag

### Severity: HIGH
**Impact:** Epistemic shocks (nuclear war, AI deception) didn't affect coordination until NEXT month

### Root Cause
**File:** `src/simulation/informationEcology.ts:342-381` (applyEpistemicShock)

Execution order issue in InformationEcologyPhase:
1. `updateInformationEcology()` - Calculates epistemic health from CURRENT state
2. `applyEpistemicShock()` - Modifies trust/misinformation/polarization
3. `calculateCoordinationModifier()` - Uses STALE epistemic health (from step 1)

**Result:**
- Month 20: Nuclear detonation occurs
  - Epistemic health = 0.65 (pre-shock)
  - Shock drops trust 0.55 → 0.35, misinfo 0.3 → 0.5, polarization 0.45 → 0.60
  - Coordination modifier uses 0.65 (WRONG - should reflect degraded state)
- Month 21: NEXT month
  - Epistemic health = 0.42 (NOW reflects shock)
  - Coordination modifier FINALLY responds (one month late)

### Fix
**Commit:** fcb36616

Added `updateEpistemicHealth()` call at end of `applyEpistemicShock()`:

```typescript
export function applyEpistemicShock(
  state: InformationEcologyState,
  severity: number,
  rng: RNGFunction
): void {
  // ... existing trust/misinformation/polarization updates ...

  // Reset shock timer
  state.daysSinceLastShock = 0;

  // CRITICAL: Recalculate epistemic health to reflect shock impact
  state.epistemicHealth = updateEpistemicHealth(state);
}
```

### Validation
After fix:
- Shocks now affect coordination in SAME month as event
- Nuclear detonation → immediate coordination drop (not delayed 1 month)
- Monte Carlo timing logs confirm synchronous response

## Issue #3: Epistemic Health Paradox (TRACKED, NOT BLOCKING)

### Status: UNDER INVESTIGATION
**Severity:** MEDIUM (non-blocking, research question)

**Observation:** Epistemic health IMPROVED (+57.5%) during societal collapse in 4/5 runs

### Hypotheses

**A. Selection Bias (LIKELY)**
Runs that survive to late-game nuclear events have BETTER baseline epistemic health than early-collapse runs.

**Mechanism:**
- Early collapse (month 20): Low epistemic health at death (e.g., 0.3)
- Late collapse (month 80): Higher baseline (e.g., 0.7), shock brings to 0.5
- Mean across collapsed runs shows improvement (survivor effect)

**B. Crisis Clarity (PLAUSIBLE)**
Existential threats reduce partisan noise, increase information-seeking.

**Research support:**
- COVID-19: Trust in science INCREASED during peak crisis (Pew 2020)
- 9/11: Brief rally effect, reduced polarization (~6 months)

**Counter-evidence:**
- COVID-19 polarization INCREASED after initial shock (2021+)
- Ukraine 2022: Massive misinformation campaigns during war

**C. Inverted Logic Bug (UNLIKELY after fixes)**
- ✅ Checked: Shocks apply correctly (trust DROP, misinfo INCREASE, polarization INCREASE)
- ✅ Checked: Epistemic health formula correct (geometric mean, proper inversions)
- ✅ Fixed: Timing lag (Bug #2) - measurements now synchronous

## Research Context

**Why Bug #1 matters:** Without coordination floor, simulation breaks basic realism. Even Syria, Afghanistan, Somalia maintain SOME local coordination (family bonds, tribal ties). Zero coordination is extinction-level - physically impossible for social species.

**Why Bug #2 matters:** 1-month lag between nuclear detonation and coordination collapse is unrealistic. Research shows immediate psychological impact of catastrophic events (Schell 1982, nuclear psychology; Petersen 2020, COVID-19 immediate response).

**Why Issue #3 matters:** If epistemic health ACTUALLY improves during collapse (not selection bias), that's a MAJOR finding about crisis response. If it's selection bias, it's a statistical artifact that needs to be documented for future researchers interpreting Monte Carlo data.

## Lessons Learned

**Compound multiplication accumulation bugs (again):**
This is the THIRD instance of this pattern:
1. Ecology score (Oct 2025) - geometric mean accumulated
2. Energy budget (Nov 2025) - multipliers compounded
3. Coordination capacity (Dec 2025) - modifiers accumulated

**Pattern to watch for:**
```typescript
// ❌ BAD - Accumulates
value = currentValue * modifier;

// ✅ GOOD - Applies to fixed base
value = baseValue * modifier;
```
