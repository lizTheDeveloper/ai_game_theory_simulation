    Interface Tier2InterventionParameters

    Sample all TIER 2 intervention parameters for a simulation run

    Called once at initialization to set epistemic uncertainty for this run. All interventions use these sampled values throughout the simulation.

    Param: rng

    Deterministic RNG function (for reproducibility via seed)

    Returns

    Sampled parameter values for all 8 interventions
