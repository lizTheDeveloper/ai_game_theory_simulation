    Interface EcosystemState

    Phase 5.4: Technology Diffusion Ecosystem State

    Tracks the spread of AI capabilities through the ecosystem. Once a capability breakthrough happens, it diffuses to other AIs over time. This creates a "capability floor" - new AIs start with baseline capabilities.
