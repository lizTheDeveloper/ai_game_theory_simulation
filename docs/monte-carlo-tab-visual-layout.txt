                           KEYBOARD NAVIGATION
═══════════════════════════════════════════════════════════════════════════════

Tab Navigation:
• Tab key: Cycle through tab buttons
• Enter/Space: Activate selected tab
• Focus visible: Glowing border (cyan)

Interactive Elements:
• All buttons keyboard-accessible
• No keyboard traps
• Focus order: logical (left→right, top→bottom)

Disabled States:
• Cannot be focused
• Visual: grayed out, cursor-not-allowed
• Screen reader: "disabled" announced
