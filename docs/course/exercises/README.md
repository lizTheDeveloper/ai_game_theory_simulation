## Exercise Template

Each exercise should include:

1. **Objective** - What will you learn?
2. **Prerequisites** - What do you need to know?
3. **Setup** - Initial configuration steps
4. **Tasks** - Step-by-step instructions
5. **Verification** - How to check your work
6. **Extensions** - Optional challenges
7. **Resources** - Links to relevant modules
