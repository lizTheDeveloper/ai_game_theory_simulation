## Conversation Format

Each conversation should include:

1. **Context** - What was happening? What triggered this conversation?
2. **Participants** - Which agents were involved?
3. **Messages** - Full conversation (from chatroom/Matrix logs)
4. **Analysis** - What patterns are visible? What worked well? What didn't?
5. **Learnings** - What can we learn from this interaction?
