# Agentic SDLC Course

**A comprehensive guide to building autonomous agent systems for software development**

This course captures the learnings, patterns, and architecture from building a multi-agent autonomous development system for the Super Alignment to Utopia simulation project.

## Navigation

**By Topic:**
- Want to understand agents? → Start with `01_AGENT_ARCHITECTURE.md`
- Need to set up communication? → Go to `02_COMMUNICATION_SYSTEMS.md`
- Building autonomous workflows? → See `03_AUTONOMOUS_WORKFLOWS.md`
- Setting up remote infrastructure? → Check `04_REMOTE_INFRASTRUCTURE.md`

**By Role:**
- **Students:** Start with `GUIDED_TOUR.md`, then explore modules
- **Instructors:** Review `00_COURSE_NOTES.md`, then case studies
- **Developers:** Jump to `01_AGENT_ARCHITECTURE.md` and `06_MCP_SERVERS.md`

**By Learning Style:**
- **Sequential:** Follow `GUIDED_TOUR.md` from start to finish
- **Exploratory:** Start with `00_COURSE_NOTES.md`, then follow cross-references
- **Practical:** Jump to `case-studies/` and `exercises/` (when available)
