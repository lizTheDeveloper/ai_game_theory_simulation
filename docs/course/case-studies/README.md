## Case Study Template

Each case study should include:

1. **Context** - What was the problem/feature?
2. **Agent Workflow** - Which agents were involved? How did they coordinate?
3. **Timeline** - When did things happen? What was the sequence?
4. **Key Decisions** - What choices were made? Why?
5. **Outcomes** - What was the result? What was learned?
6. **Lessons** - Patterns that emerged, things to replicate/avoid
