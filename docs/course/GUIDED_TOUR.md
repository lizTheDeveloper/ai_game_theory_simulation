# Guided Tour: Agentic SDLC

**Recommended learning path through the course materials**

This tour provides a suggested sequence for learning about autonomous agent systems. The modules are listed as an **unordered list** for easy reordering as the course evolves.

---

## Learning Path

### Phase 1: Foundation

- [ ] **00_COURSE_NOTES.md** - Start here: High-level overview, what is this system, key concepts

- [ ] **01_AGENT_ARCHITECTURE.md** - Understand agent system design, personalities, memory hierarchy

- [ ] **02_COMMUNICATION_SYSTEMS.md** - Learn how agents coordinate via chatroom and Matrix

### Phase 2: Autonomous Systems

- [ ] **03_AUTONOMOUS_WORKFLOWS.md** - Deep dive into autonomous worker, channel monitor, orchestrator patterns

- [ ] **04_REMOTE_INFRASTRUCTURE.md** - Set up continuous development on remote VM

- [ ] **05_PLANNING_COORDINATION.md** - Roadmap management, devlogs, planning systems

### Phase 3: Implementation

- [ ] **06_MCP_SERVERS.md** - Build custom MCP servers, optimize token efficiency

- [ ] **08_QUALITY_GATES.md** - Research validation, architecture review, continuous quality control

- [ ] **09_CRISIS_MITIGATION.md** - Learn from real crises: property access, research citation, organizational memory

### Phase 4: Advanced Topics

- [ ] **07_TESTING_VALIDATION.md** - Monte Carlo validation, agent behavior testing, integration strategies

- [ ] **case-studies/** - Study real-world examples of agent workflows

- [ ] **exercises/** - Hands-on practice (when available)

- [ ] **conversations/** - See agents in action (when available)

---

## Customization

**Feel free to reorder these modules** based on your needs:

- **Quick Start:** Phase 1 → Phase 3 → case-studies
- **Build Your Own:** Phase 1 → Phase 2 → Phase 4
- **Learn from Mistakes:** Phase 1 → 09_CRISIS_MITIGATION.md → case-studies

**The list is intentionally unordered** - drag and drop to create your own learning path.

---

## Prerequisites

- Basic understanding of software development
- Familiarity with TypeScript/Node.js (helpful but not required)
- Interest in autonomous systems and AI agents

---

## Time Estimates

- **Phase 1:** 2-3 hours (foundation concepts)
- **Phase 2:** 3-4 hours (autonomous systems)
- **Phase 3:** 2-3 hours (implementation details)
- **Phase 4:** Variable (advanced topics, case studies)

**Total:** ~10-15 hours for complete tour

---

*This tour is a living document - modules can be reordered as the course evolves.*
