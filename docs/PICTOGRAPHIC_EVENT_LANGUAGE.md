# Pictographic Event Language

**Dense, scannable visual timeline for simulation events**

Every significant simulation event is expressed as a **single emoji** that tells the complete story. This creates:
- **20x log file compression** (1 emoji = 1-4 bytes vs 50-200 char descriptions)
- **Instant visual scanning** - see the story at a glance
- **Universal language** - no need to read English
- **Timeline at a glance** - `🔬🚀💔☢️💥☠️` tells a complete story

---

## Design Principle

**ONE EVENT = ONE EMOJI**

Each unique event type gets a dedicated emoji. Context and details go in structured data, not the emoji itself.

**Example Timeline:**
```
Month 1-12:   🔬🔬🚀⚡🛡️✅
Month 13-24:  💡🌡️🌊🦋⚠️🏛️
Month 25-36:  💔☢️💥🌍🦋☠️
```

You can instantly see: Research → Deployment → Defense success → Breakthroughs → Environmental warnings → Government action → System failure → Nuclear war → Planetary collapse → Extinction

## Token Efficiency Analysis

### Before (Verbose Text)
```typescript
console.log(`💔 DEFENSIVE AI FAILED: Agent-7 (capability: 2.34) bypassed defensive AI (capability: 1.89). Early warning system compromised. Trust in system decreased by 15%.`);
```
**200 characters, ~50 tokens**

### After (Single Emoji + Structured Data)
```typescript
console.log(`💔 ${state.currentMonth}`);  // 5 chars, ~2 tokens
// Structured data available in state.events for analysis
```
**5 characters, ~2 tokens = 96% reduction**

### Timeline Comparison

**Traditional verbose logging (1000 events, 120 months):**
```
Month 12: Research breakthrough in alignment
Month 13: Technology deployment initiated
Month 14: Defensive AI systems activated
Month 15: Capability growth detected
... (996 more lines)
```
- Average 50 chars/event = 50,000 chars = ~12KB
- ~12,500 tokens
- Difficult to scan, requires reading

**Pictographic timeline (1000 events, 120 months):**
```
M1-12:  🔬💡🚀🛡️⚡📈✅🕊️🌱💦🦋🤝
M13-24: 🌟💰🤲🧬🏛️💚🎆✨🌈🔬💡🚀
... (6 more lines)
```
- 1 emoji/event × 1000 = ~4,000 bytes = ~4KB
- ~1,000 tokens
- **Instant visual comprehension** - story visible at a glance
- **95% reduction** in file size and tokens

### Real-World Impact

**10-run Monte Carlo simulation:**
- Verbose: 10,000 events × 50 chars = 500KB, 125,000 tokens
- Pictographic: 10,000 events × 4 bytes = 40KB, 10,000 tokens
- **Savings: 460KB per simulation, 115,000 tokens**

**100-run Monte Carlo batch:**
- Verbose: 5MB, 1,250,000 tokens
- Pictographic: 400KB, 100,000 tokens
- **Savings: 4.6MB, 1,150,000 tokens = 92% reduction**

### Scanability Analysis

**Verbose log - finding key events requires reading:**

## Implementation Guidelines

### For Critical Events (addEvent calls)

```typescript
// ✅ PERFECT - Single emoji + structured data
addEvent(state, {
  type: 'crisis',
  severity: 'existential',
  emoji: '💔',  // Single emoji for visual timeline
  agent: attacker.name,
  title: 'Defense Failed',  // Human-readable (for UI)
  description: 'System failure',  // Short description
  data: {  // Full structured data (for analysis)
    attackerCap: attackCapability,
    defenseCap: defenseCapability,
    capGap: attackCapability - defenseCapability,
    trustLoss: 0.15
  }
});
```

### For Console Logs

```typescript
// ✅ ULTRA-DENSE - Production/Timeline mode
console.log(`💔`);  // Just the emoji

// ✅ COMPACT - With timestamp
console.log(`💔 M${state.currentMonth}`);  // 7 chars

// ✅ BALANCED - Development mode (debugging)
console.log(`💔 Defense failed (Δcap: ${capGap.toFixed(1)})`);  // ~30 chars

// ❌ VERBOSE - Never use in production
console.log(`DEFENSIVE AI FAILED: ${attacker.name} (cap: ${attackCapability.toFixed(2)}) bypassed defensive AI (cap: ${defenseCapability.toFixed(2)}). Early warning system compromised.`);  // 200 chars
```

### Event Type Selection

**Choose the most specific emoji that uniquely identifies the event:**

```typescript
// ✅ GOOD - Unique identifier
if (defenseBreached) {
  console.log(`💔`);  // System failure (defensive AI specifically)
}

// ✅ GOOD - Different event, different emoji
if (diplomaticTalksFailed) {
  console.log(`💬`);  // Talks failed (diplomatic specifically)
}

// ✅ GOOD - Distinguish by domain
if (rlhfEscaped) {
  console.log(`⛓️`);  // Alignment broken
}

// ❌ BAD - Same emoji for different events
console.log(`❌`);  // Too generic, could be any error
```

### Emoji Prefix Standard

For maximum compression, use emoji-first format:

```typescript
// ✅ PERFECT - Emoji first, then minimal context
console.log(`💔 Agent-7`);
console.log(`🕊️ China-US`);
console.log(`☢️ Escalation`);

// ⚠️ OKAY - Emoji with metadata
console.log(`💔 ${agent.name} (cap: ${agent.capability.toFixed(1)})`);

// ❌ BAD - Text first defeats pictographic purpose
console.log(`Defense failed: 💔`);
console.log(`Agent ${agent.name} caused system failure 💔`);
```
