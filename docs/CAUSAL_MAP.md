## Critical Paths

### Utopia (RARE - usually a bug when achieved)

**Requirements (ALL must be true):**
1. ✅ 6/6 upward spirals active for 12+ consecutive months
2. ✅ Sustainability >= 65%
3. ✅ No active crises
4. ✅ QoL metrics above paradigm-specific thresholds
5. ✅ Population stable/growing
6. ✅ No recent extinctions

**Why rare**: Upward spirals require sustained prosperity + trust + institutions + breakthroughs simultaneously. Any crisis disrupts.

### Dystopia Paths

**Control Dystopia:**
- AI alignment → High government control
- High control + Low trust → Oppression
- Oppression + AI surveillance → Control Dystopia

**Meaning Collapse:**
- AI capability → Automation
- Automation + Weak UBI → Unemployment
- Unemployment + No cultural adaptation → Meaning crisis
- Meaning crisis → Social fragmentation → Collapse

**Environmental Dystopia:**
- Fossil industry political power → Clean tech resistance
- Resistance + Climate crisis → Runaway warming
- Warming → Crop failure + Habitability loss → Dystopia

### Extinction Cascades

**Famine → Nuclear:**
- Climate → Crop failure → Famine
- Famine → Migration → Border tensions
- Tensions → Nuclear brinkmanship → Accidental launch

**Ocean → Collapse:**
- CO2 → Ocean acidification → Coral death
- Coral death → Fishery collapse → Protein crisis
- Protein crisis → Famine → Social collapse

**Phosphorus → Starvation:**
- Phosphorus depletion → Fertilizer shortage
- Fertilizer shortage → Crop yields crash
- Crop crash → Global famine → Mass mortality

## Emergent Behaviors to Catalog

### Known Emergent Patterns

1. **"Golden Age Trap"**
   - High QoL + High production → Looks like utopia
   - But: Environmental/social debt accumulating silently
   - Threshold crossed → Rapid collapse
   - **Reality Check**: This matches historical patterns (see: Easter Island)

2. **"Control Dystopia Spiral"**
   - Safety concerns → Government control ↑
   - Control → AI resentment ↑
   - Resentment → Deception risk ↑
   - Deception → More control needed (vicious cycle)
   - **Reality Check**: This is theoretically sound but no 2025 empirical evidence

3. **"Trust Paradox"**
   - High trust → More AI deployment
   - More deployment → More failure surface area
   - One major failure → Trust collapse
   - Trust collapse → Paranoia → Control spiral
   - **Reality Check**: Matches social trust literature

### Suspected Oversimplifications (Need Refinement)

When we find "too easy" utopia, it's usually one of these:

1. **Resource constraints too forgiving**
   - Real supply chains are brittle
   - Bottlenecks should cascade more

2. **Social adaptation too fast**
   - Real cultural change takes generations
   - Meaning crisis recovery likely slower

3. **Technology deployment too smooth**
   - Real innovation faces resistance we're not modeling
   - Regulatory friction underestimated

4. **Crisis interaction too linear**
   - Real cascades have more amplification
   - Threshold effects sharper than modeled
