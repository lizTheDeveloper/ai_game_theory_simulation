## Executive Summary

**The Sixth Mass Extinction is underway, but recent data shows a complex picture.** While extinction rates remain 100-1,000x above background rates, there's evidence of declining extinction rates in the last century for some taxa, running counter to popular narratives of accelerating collapse.

**Key Findings:**
- **Current extinction rate:** 1,000-10,000x above natural background (~1 E/MSY)
- **Threatened species:** ~25% of assessed species (~1 million species at risk)
- **Recent trend (2025):** Declining extinction rates in last 100 years for vertebrates, arthropods, plants (contradicts acceleration narrative)
- **Freshwater crisis:** 25% of freshwater fauna threatened, 89 confirmed extinctions + 178 suspected since 1500
- **20th century biodiversity loss:** 2-11% global decline (multi-model assessment)
- **Future driver shift:** Climate change becomes primary driver by 2050 (currently land-use change)

**Critical Context:** The extinction crisis is real and severe (30-120x fossil record rates), but **recent data shows stabilization or decline in extinction rates** for many taxa in the last century, likely due to conservation efforts. This creates a nuanced picture: ongoing crisis, but not accelerating collapse.

## 2. Contradictory Finding: Declining Extinction Rates in Last Century (2025)

### 2.1 Saban & Wiens Study (Royal Society B, 2025)

**Citation:** Saban, J. & Wiens, J.J. (2025). "Unpacking the extinction crisis: rates, patterns and causes of recent extinctions in plants and animals." *Proceedings of the Royal Society B: Biological Sciences*.
- **DOI:** 10.1098/rspb.2025.1717
- **Publication Date:** 2025

**Key findings:**
- Extinction rates have **increased over the last five centuries** (long-term trend)
- BUT: Extinction rates have **generally declined in the last 100 years** (recent trend)
- Taxa showing declining rates: **vertebrates, arthropods, plants**
- This runs **counter to the popular narrative** of accelerating biodiversity collapse

**Interpretation:** Conservation efforts (protected areas, captive breeding, species legislation) may be slowing extinction rates for some taxa, even as biodiversity loss continues.

**Citation:** Mongabay (November 2025). "A slowdown, not salvation: what new extinction data reveal about the state of life on Earth"
- **URL:** https://news.mongabay.com/2025/11/a-slowdown-not-salvation-what-new-extinction-data-reveal-about-the-state-of-life-on-earth/
- **Context:** "Slowdown" in extinction rates ≠ "salvation" - crisis continues, just not accelerating as previously thought

**Critical Caveat:** Declining extinction rates ≠ biodiversity recovery. **Population declines, habitat loss, and ecosystem degradation continue** even if fewer species are going fully extinct.

## 8. Simulation Parameters (Recommendations)

### 8.1 Extinction Rate Formula

```typescript
function calculateExtinctionRate(
  humanPressure: number, // 0.0 (pristine) to 1.0 (maximum pressure)
  climateChange: number, // °C warming above preindustrial
  landUseIntensity: number, // 0.0 to 1.0 (fraction of land converted)
  month: number // Time since 2025 (driver shift over time)
): number {
  // Background extinction rate (E/MSY)
  const backgroundRate = 1.0; // 1 extinction per million species per year

  // Current multiplier above background (2025 baseline)
  const baselineMultiplier = 1000; // Conservative estimate (1,000x)

  // Driver weights (shift over time)
  const yearsElapsed = month / 12;
  const landUseWeight = Math.max(0.6 - yearsElapsed * 0.012, 0.3); // 60% → 30% by 2050
  const climateWeight = Math.min(0.4 + yearsElapsed * 0.012, 0.7); // 40% → 70% by 2050

  // Pressure components
  const landUsePressure = landUseIntensity * landUseWeight;
  const climatePressure = (climateChange / 4.0) * climateWeight; // Normalized to 4°C
  const totalPressure = landUsePressure + climatePressure;

  // Extinction multiplier (nonlinear - accelerates with pressure)
  const extinctionMultiplier = baselineMultiplier * Math.pow(1 + totalPressure, 2);

  // E/MSY rate
  const extinctionRate = backgroundRate * extinctionMultiplier;

  return extinctionRate; // E/MSY
}
```

### 8.2 Threatened Species Fraction

```typescript
function calculateThreatenedSpeciesFraction(
  extinctionRate: number, // E/MSY from above
  conservationEffort: number // 0.0 (none) to 1.0 (maximum)
): number {
  // Base threatened fraction (IPBES 2025: ~25%)
  const baselineThreatened = 0.25;

  // Scaling factor from extinction rate
  const extinctionScaling = Math.log10(extinctionRate) / Math.log10(1000); // Normalized to 1,000x

  // Conservation benefit (reduces threatened fraction)
  const conservationBenefit = conservationEffort * 0.4; // Max 40% reduction

  // Final threatened fraction
  let threatenedFraction = baselineThreatened * (1 + extinctionScaling) - conservationBenefit;
  threatenedFraction = Math.max(0.05, Math.min(threatenedFraction, 0.95)); // Clamp [5%, 95%]

  return threatenedFraction;
}
```

### 8.3 Biodiversity Decline Rate (% per decade)

```typescript
function calculateBiodiversityDecline(
  extinctionRate: number, // E/MSY
  habitatLoss: number, // Fraction of habitat destroyed
  climateVelocity: number // km/year species need to shift ranges
): number {
  // 20th century decline: 2-11% (Science 2024)
  const historicDecline = 0.065; // 6.5% midpoint per century

  // Current drivers (normalized)
  const extinctionComponent = (extinctionRate / 1000) * 0.03; // 3% per decade per 1,000x multiplier
  const habitatComponent = habitatLoss * 0.05; // 5% per decade per unit habitat loss
  const climateComponent = (climateVelocity / 10) * 0.02; // 2% per decade per 10 km/year velocity

  // Total decline per decade
  const declinePerDecade = extinctionComponent + habitatComponent + climateComponent;

  return declinePerDecade; // Fraction lost per decade
}
```

## 9. Key Insights for Simulation

### 9.1 Declining Extinction Rates ≠ No Crisis

**Finding:** Saban & Wiens (2025) show declining extinction rates in last century for many taxa.

**Simulation implication:**
- Model **conservation effectiveness** as a damping factor on extinction rates
- Show **stabilization, not acceleration** of extinction rates under conservation scenarios
- But: **Population declines and ecosystem degradation continue** even if extinction rates stabilize

### 9.2 Driver Shift by 2050

**Finding:** Climate change becomes primary driver by 2050 (currently land-use change).

**Simulation implication:**
- Time-varying driver weights
- Early game (2025-2040): Land-use change dominates
- Late game (2050+): Climate change dominates
- Trade-offs: Protecting habitat now doesn't prevent climate-driven extinctions later

### 9.3 Freshwater Crisis Disproportionate

**Finding:** 25% of freshwater fauna threatened (Nature 2025).

**Simulation implication:**
- Model freshwater ecosystems separately (higher extinction risk)
- Dam construction, pollution, water extraction disproportionately impact freshwater species
- Restoration potential: Removing dams, reducing pollution can reverse some declines

### 9.4 Economic Opportunity from Conservation

**Finding:** IPBES 2024 - USD 10 trillion business value, 395M jobs by 2030 from conservation.

**Simulation implication:**
- Conservation is not zero-sum (economic vs. ecology)
- Green economy transition can create jobs and reduce extinction risk simultaneously
- Policy incentives matter: Make conservation profitable

## 10. Research Gaps and Future Directions

### 10.1 Taxonomic Bias

**Gap:** Most extinction data from vertebrates, plants. Invertebrates, fungi, microbes under-assessed.

**Future research need:** Expand assessments to under-studied taxa (estimated 5-10M unnamed species).

### 10.2 Population Declines vs. Extinctions

**Gap:** Extinction is final stage. Population declines (abundance, biomass) occur decades earlier.

**Future research need:** Metrics beyond species richness (abundance, functional diversity, ecosystem services).

### 10.3 Interaction Effects

**Gap:** Climate + habitat + pollution + invasives interact nonlinearly.

**Future research need:** Synergistic effects modeling (e.g., climate-stressed species more vulnerable to disease).
