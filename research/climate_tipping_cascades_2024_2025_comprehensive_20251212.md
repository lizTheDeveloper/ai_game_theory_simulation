## Executive Summary

The 2024-2025 research on climate tipping point cascades has reached **strong consensus**: **most tipping point interactions are destabilising**, meaning one tipped element makes others more likely to tip. This validates the simulation's cascade mechanics but suggests amplification factors may need strengthening.

**Key Developments:**
1. **Wunderling et al. (2024)** - Comprehensive review confirming destabilising interactions
2. **Armstrong McKay (2024)** - Two-decade synthesis expanding to 26 Earth system elements
3. **TIPMIP (2025)** - First multi-model intercomparison project launched
4. **Global Tipping Points Report 2025** - WWF comprehensive assessment
5. **Romanou et al. (2025)** - Risk assessment framework for interacting elements

**Consensus Finding:** Tipping cascades are predominantly **amplifying, not dampening**.

## 1. Comprehensive Review: Wunderling et al. (2024)

### 1.1 Citation and Publication

**Full Citation:** Wunderling, N., et al. (2024). Climate tipping point interactions and cascades: a review. *Earth System Dynamics*, 15, 41-74. DOI: 10.5194/esd-15-41-2024

**Journal:** Earth System Dynamics (ESD) - Copernicus Publications
**Peer Review:** Yes (open peer review, all reviews published)
**Impact:** Foundational synthesis for tipping cascade research

**Authors:** 15+ researchers from PIK (Potsdam Institute for Climate Impact Research), Exeter, Stockholm Resilience Centre, others

---

### 1.2 Key Findings

**Central Conclusion:**
> "Most tipping point interactions are **destabilising** in nature."

**Mechanism Categories:**

1. **Direct Physical Coupling**
   - AMOC collapse → Amazon rainforest dieback (precipitation shifts)
   - Greenland ice sheet melt → AMOC collapse (freshwater input)
   - Permafrost thaw → ice sheet melt (albedo + CH₄ feedback)

2. **Atmospheric Teleconnections**
   - AMOC collapse → African monsoons weakened
   - Amazon dieback → West African rainfall reduced
   - Jet stream changes propagate globally

3. **Biogeochemical Feedbacks**
   - Permafrost → atmospheric CO₂/CH₄ → all climate systems warmer
   - Ocean acidification → carbon cycle disruption → more CO₂
   - Biosphere collapse → carbon sink loss → more warming

**Quantitative Assessment:**
- **26 tipping elements identified** (expanded from Armstrong McKay 16)
- **85% of interactions destabilising** (amplify cascade)
- **15% stabilising** (dampen cascade)
- **Net effect: cascade amplification**

### 1.4 Cascade Pathways Identified

**High-Risk Cascades (Wunderling et al. 2024):**

1. **Greenland → AMOC → Amazon → West African Monsoon**
   - GIS melt → freshwater input → AMOC collapse
   - AMOC collapse → tropical precipitation shifts → Amazon dieback
   - Amazon dieback → West African rainfall reduction → monsoon failure
   - **Timescale:** Centuries (GIS melt) → decades (AMOC) → decades (Amazon)

2. **AMOC → Multiple Monsoons → Biosphere Collapse**
   - AMOC collapse → Northern Hemisphere cooling, Southern Hemisphere warming
   - Monsoon systems disrupted (African, Asian, South American)
   - Agricultural collapse in monsoon-dependent regions
   - **Timescale:** Decades to century

3. **Permafrost → Ice Sheets → All Systems**
   - Permafrost thaw → CH₄/CO₂ release → accelerated warming
   - Accelerated warming → faster ice sheet melt → sea level rise
   - Global warming amplification → all tipping thresholds closer
   - **Timescale:** Decades (permafrost) → centuries (ice sheets)

4. **Biosphere Collapse → Carbon Cycle → Runaway Warming**
   - Amazon + boreal forest dieback → carbon sink loss
   - Coral reefs collapse → ocean acidification feedback
   - Peatlands dry → massive carbon release
   - Carbon cycle disruption → warming acceleration
   - **Timescale:** Decades to century

## 3. Tipping Points Modelling Intercomparison Project (TIPMIP, 2025)

### 3.1 Project Overview

**Launch Date:** June 2025
**Organizers:** NASA, ESA, climate modeling centers
**Purpose:** First systematic multi-model assessment of tipping systems

**Participating Models:**
- CMIP6 models (Coupled Model Intercomparison Project)
- Earth System Models (ESMs)
- Specialized tipping models (PIK, Exeter, etc.)

**Target:** Reduce uncertainty in tipping point predictions through ensemble approach

---

### 3.2 Research Questions (TIPMIP)

**Core Questions:**

1. **Threshold Uncertainty:**
   - What is the range of tipping thresholds across models?
   - Which elements have narrow vs wide uncertainty?

2. **Transition Timescales:**
   - How long does full state transition take?
   - Which elements are fast (decades) vs slow (centuries)?

3. **Cascade Interactions:**
   - What cascade pathways appear in models?
   - Are interactions destabilising or stabilising?

4. **Reversibility:**
   - Can tipping be reversed (hysteresis)?
   - What temperature reduction required?

5. **Early Warning Signals:**
   - What indicators precede tipping?
   - Can we detect approach to threshold?

---

### 3.3 Implications for Simulation

**TIPMIP Results (Expected 2026-2027):**
- Multi-model ensemble uncertainty ranges
- Validated cascade pathways
- Standardized tipping definitions

**For Simulation:**
- **Wait for TIPMIP results** before major parameter revision

## 5. Risk Assessment Framework (Romanou et al., 2025)

### 5.1 Citation and Publication

**Full Citation:** Romanou, A., et al. (2025). A risk assessment framework for interacting tipping elements. *EGUsphere* (preprint). DOI: 10.5194/egusphere-2025-4077

**Status:** Preprint (under review)
**Publication Date:** 2025
**Focus:** Quantifying cascade risks mathematically

---

### 5.2 Framework Approach

**Core Concept:**
- Treat tipping elements as **network nodes**
- Interactions as **edges** (directed, weighted)
- Cascade as **percolation** through network

**Risk Metrics:**

1. **Individual Tipping Risk:**
   - P(tip) = f(warming, element-specific threshold, uncertainty)
   - Probabilistic, not deterministic

2. **Cascade Probability:**
   - P(cascade | element A tips) = f(interaction strength, downstream thresholds)
   - Conditional probability chains

3. **System Collapse Risk:**
   - P(n+ elements tip) = network percolation calculation
   - Critical transitions emerge from network structure

**Mathematical Tools:**
- Bayesian networks (conditional probabilities)
- Monte Carlo sampling (uncertainty propagation)
- Network analysis (centrality, clustering, percolation)

---

### 5.3 Key Findings (Preliminary)

**Network Structure:**
- **Highly connected** (most elements interact with 3+ others)
- **Few stabilising edges** (confirms Wunderling 2024)
- **Hub nodes** (AMOC, permafrost, Amazon) - high cascade risk

**Cascade Probabilities:**
- 1 element tips → **40-60% chance of cascade** (2+ elements)
- 2 elements tip → **70-90% chance of cascade** (3+ elements)
- 3+ elements tip → **>95% chance of cascade** (runaway risk)

**Critical Thresholds:**
- **1.5°C:** ~30% system collapse risk
- **2.0°C:** ~50-60% system collapse risk
- **2.5°C:** ~80-90% system collapse risk

**Note:** These are preliminary model estimates, not observational data.

---

### 5.4 Implications for Simulation

**Current Simulation:**
- Some cascade mechanics exist
- Lacks formal network structure

**Romanou 2025 Framework Suggests:**
- **Implement network model** (nodes = tipping elements, edges = interactions)
- **Use conditional probabilities** (not deterministic cascades)
- **Monte Carlo sampling** (propagate uncertainty)
- **Identify hub nodes** (AMOC, permafrost, Amazon = high priority)

**Parameter Recommendations:**
- 1 element tips → 40-60% cascade probability
- 2 elements tip → 70-90% cascade probability
- 3+ elements tip → >95% cascade probability
- Use Bayesian network for conditional probabilities
