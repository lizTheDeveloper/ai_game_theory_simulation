## Additional Sources for Context-Dependent Effectiveness

### Low-Income Context: GiveDirectly Kenya

**Citation:**
Haushofer, Johannes, and Jeremy Shapiro. "The Short-Term Impact of Unconditional Cash Transfers to the Poor: Experimental Evidence from Kenya." *Quarterly Journal of Economics* 131, no. 4 (2016): 1973-2042. https://doi.org/10.1093/qje/qjw025

**Long-term follow-up:**
Haushofer, Johannes, and Jeremy Shapiro. "The Long-Term Impact of Unconditional Cash Transfers: Experimental Evidence from Kenya." Busara Center for Behavioral Economics, 2018.

**Findings:**
- **Short-term (9 months post-transfer):**
  - Household monthly consumption increased from $158 PPP to $193 PPP (~22% increase)
  - Large increases in assets, earnings, food security, psychological well-being
  - Reduction in domestic violence

- **Long-term (3 years post-transfer):**
  - 40% more assets than control ($422 PPP vs. baseline)
  - Equals 60% of initial transfer ($709 PPP) retained as assets
  - Effects on income and consumption **did not persist**

**Context:** Rural Kenya, extremely low baseline income (~$158/month), one-time large transfers ($404-$1,525)

### 2. Add Temporal Dynamics to Simulation

**Current Implementation Problem:**
The UBI floor is static - it applies the same bonus regardless of time elapsed.

**Research-Backed Enhancement:**
```typescript
export function calculateUBIMentalHealthBonus(
  economicStage: number,
  hasGenerousUBI: boolean,
  monthsSinceUBIAdoption: number // NEW PARAMETER
): number {
  // Base bonus (Year 1)
  let baseBonus = 0;

  if (economicStage >= 3) {
    // Post-scarcity: sustained effects (different mechanism)
    baseBonus = hasGenerousUBI ? 0.20 : 0.12;
  } else {
    // Pre-transition: short-lived effects (OpenResearch 2024)
    baseBonus = hasGenerousUBI ? 0.10 : 0.06;

    // DECAY FUNCTION: Effects fade over 12-24 months
    const decayFactor = Math.max(0.3, 1 - (monthsSinceUBIAdoption / 24));
    baseBonus *= decayFactor;
  }

  return baseBonus;
}
```

**Research Justification:**
- Miller et al. (2024): Effects "large but short-lived," faded by Year 2
- Finland (Kangas 2019): Sustained improvements, but MUCH smaller transfer in high-income context
- Post-scarcity assumption: Different mechanism (existential security, not just cash)

### 3. Add Context-Dependent Effectiveness Model

**Missing from Current Implementation:**
The model treats UBI as having uniform effects across all contexts.

**Research Shows:**
- **Low-income (Kenya):** Large short-term consumption effects, 60% asset retention at 3 years
- **Middle-income (Finland):** Modest mental health improvements, minimal employment effects
- **High-income (Alaska):** No employment effects, slight increase in part-time work

**Simulation Enhancement:**
```typescript
export function calculateUBIFloor(
  economicStage: number,
  hasGenerousUBI: boolean,
  gdpPerCapita: number, // NEW: context-dependent
  unemploymentRate: number // NEW: crisis-dependent
): number {
  // Base floor varies by economic development
  let baseFloor = 0;

  if (economicStage >= 3) {
    // Post-scarcity: Strong UBI floor
    baseFloor = hasGenerousUBI ? 0.90 : 0.75;
  } else if (gdpPerCapita < 10000) {
    // Low-income context: Large consumption effect
    baseFloor = hasGenerousUBI ? 0.70 : 0.60;
  } else if (gdpPerCapita < 40000) {
    // Middle-income context: Modest effect
    baseFloor = hasGenerousUBI ? 0.60 : 0.50;
  } else {
    // High-income context: Smaller effect (Alaska-style)
    baseFloor = hasGenerousUBI ? 0.55 : 0.45;
  }

  // CRISIS MULTIPLIER: UBI more effective during high unemployment
  // Research: Food security benefits larger during COVID crisis
  if (unemploymentRate > 0.10) {
    const crisisBonus = Math.min(0.15, (unemploymentRate - 0.10) * 0.5);
    baseFloor += crisisBonus;
  }

  return Math.min(0.95, baseFloor); // Cap at 0.95
}
```
