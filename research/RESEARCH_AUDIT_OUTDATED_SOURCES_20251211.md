## Methodology Notes

**Audit Process:**
1. Scanned 782 research markdown files for frontmatter metadata
2. Extracted `oldest_source`, `newest_source`, `last_verified`, `used_in_simulation` fields
3. Categorized by domain (climate, AI, social, other)
4. Prioritized by simulation relevance and age of oldest source

**Limitations:**
- Some files lack explicit `used_in_simulation: true` flag but are clearly used
- Frontmatter metadata quality varies (some files missing fields)
- Can't assess parameter extraction quality without reading full file
- Some "old" sources are appropriately foundational (game theory, historical case studies)

**False Positives:**
- Foundational theory sources (Hardin 1968, Sen 1981) are intentionally old
- Historical case studies (Black Death, WWII) don't age out
- Meta-audit files (research_audit_*.md) cite old sources by design

**True Positives:**
- Empirical climate parameters from pre-2020 data likely outdated
- Technology deployment rates from pre-2020 need updates
