## 1. Climate Mortality Pathways (Evidence-Based Parameters)

### 1.1 Heat-Related Mortality

**Temperature-Mortality Relationship:**
- **Linear scaling:** 1-3% mortality increase per 1°C temperature rise
- **IPCC AR6 projection:** 250,000 excess deaths/year by 2050 attributable to climate change
- **Attribution:** 37.0% (range 20.5-76.3%) of warm-season heat deaths attributable to anthropogenic climate change

**Critical Temperature Thresholds:**
- **Theoretical wet-bulb limit:** 35°C (upper physiological tolerance)
- **Empirical critical threshold:** ~30.55°C average wet-bulb temperature for young, healthy individuals
- **ACTUAL mortality threshold:** 28-31°C wet-bulb (2003 European, 2010 Russian heat waves)
- **Why lower?** Infrastructure mismatch - regions lack cooling infrastructure, elderly/vulnerable populations

**Modeling Recommendation:**
```typescript
// Heat mortality risk = f(wet-bulb temperature, infrastructure capacity, population vulnerability)
heatMortalityRisk = baseRisk *
  temperatureScaling(wetBulbTemp) *
  infrastructureMismatch(coolingCapacity, regionalNeed) *
  populationVulnerability(elderly, health)

// Temperature scaling (non-linear above thresholds)
function temperatureScaling(wetBulbTemp: number): number {
  if (wetBulbTemp < 28) return 1.0;
  if (wetBulbTemp < 31) return 1.0 + 0.10 * (wetBulbTemp - 28); // 10% increase per °C
  if (wetBulbTemp < 35) return 1.3 + 0.25 * (wetBulbTemp - 31);  // 25% increase per °C
  return 2.3 + 0.50 * (wetBulbTemp - 35); // 50% increase per °C beyond survival limit
}

// Infrastructure mismatch multiplier
function infrastructureMismatch(coolingCapacity: number, need: number): number {
  const gap = Math.max(0, need - coolingCapacity);
  return 1.0 + (gap / need) * 2.0; // Up to 3x mortality with zero infrastructure
}
```

**Regional Examples:**
- **Persian Gulf:** High wet-bulb temps but LOW mortality (widespread A/C, cultural adaptation)
- **Northeast India, West Africa:** Lower temps but HIGH mortality (scarce cooling infrastructure)
- **2003 Europe:** 28°C wet-bulb, 70,000+ deaths (infrastructure unprepared)

- **M (Magnitude):** Deaths per event
- **D (Duration):** Length of exposure
- **F (Frequency):** Events per year

### 1.3 Infrastructure Mismatch as Primary Mortality Driver

**Key Finding:** Infrastructure gap, not just temperature, determines mortality.

**Infrastructure Mismatch Index (IMI):**
```typescript
interface InfrastructureMismatch {
  cooling: {
    capacity: number;      // A/C units per capita, public cooling centers
    need: number;          // Based on wet-bulb temperature exposure days
    gap: number;           // need - capacity
  };
  flood_protection: {
    capacity: number;      // Seawalls, drainage, early warning systems
    need: number;          // Based on storm surge risk, precipitation
    gap: number;
  };
  emergency_services: {
    capacity: number;      // Hospitals, ambulances, shelters per capita
    need: number;          // Based on disaster frequency
    gap: number;
  };
}

// Overall infrastructure mismatch multiplier
function calculateIMI(mismatch: InfrastructureMismatch): number {
  const coolingGap = mismatch.cooling.gap / mismatch.cooling.need;
  const floodGap = mismatch.flood_protection.gap / mismatch.flood_protection.need;
  const emergencyGap = mismatch.emergency_services.gap / mismatch.emergency_services.need;

  // Geometric mean to avoid zero cancellation
  return Math.pow(
    (1 + coolingGap) * (1 + floodGap) * (1 + emergencyGap),
    1/3
  );
}
```

**Regional Vulnerability:**
- **High vulnerability:** Northeast India, coastal West Africa (low infrastructure, high exposure)
- **Medium vulnerability:** Southeast Asia, Central America (moderate infrastructure, high exposure)
- **Low vulnerability:** Persian Gulf, Singapore (high infrastructure, high exposure)

```typescript
// Non-migratory species die-off
interface SpeciesVulnerability {
  mobilityConstraint: number;     // 0 = fully mobile, 1 = sessile
  growthRate: number;             // Years to reproductive maturity
  rangeShiftSpeed: number;        // km/year species can migrate
  climateVelocity: number;        // km/year isotherms moving
  habitatFragmentation: number;   // 0 = continuous, 1 = isolated patches
}

function calculateSpeciesMortality(species: SpeciesVulnerability, climate: ClimateState): number {
  // Climate velocity mismatch
  const velocityGap = Math.max(0, climate.climateVelocity - species.rangeShiftSpeed);

  // Keystone species multiplier (affects other species)
  const keystoneMultiplier = species.isKeystone ? 2.5 : 1.0;

  // Mortality from inability to track climate
  const trackingMortality = velocityGap / climate.climateVelocity;

  // Habitat fragmentation barrier
  const fragmentationBarrier = species.habitatFragmentation * 1.5;

  return Math.min(1.0,
    trackingMortality * (1 + fragmentationBarrier) * keystoneMultiplier
  );
}
```

```typescript
// Calculate cascading tipping point risk
function calculateCascadeRisk(boundaries: PlanetaryBoundary[]): number {

  const baseRisk = transgressedCount / boundaries.length;

  const cascadeMultiplier = Math.pow(1.5, transgressedCount - 1);

  return Math.min(1.0, baseRisk * cascadeMultiplier);
}
```

```typescript
// Enhanced BII formula
function calculateBII(region: EcosystemState): number {
  const nativeAbundance = region.nativeSpecies.reduce((sum, s) => sum + s.abundance, 0);
  const nativeBaseline = region.nativeSpecies.reduce((sum, s) => sum + s.historicAbundance, 0);

  // Penalty for overabundance (invasive native species)
  const overabundancePenalty = calculateOverabundance(region.nativeSpecies);

  // Penalty for invasive alien species
  const invasivePenalty = region.invasiveSpecies.reduce((sum, s) => sum + s.abundance, 0) / nativeBaseline;

}
```

### 2.4 Climate Velocity and Range Shift Failure

**Key Finding:** Species must move faster than ever while facing more barriers than ever.

**Climate Velocity:**
- **Definition:** Speed at which isotherms (lines of constant temperature) move across landscape
- **Typical values:** 0.5-10 km/year (faster in flat regions, slower in mountains)
- **Species constraint:** Many species can only migrate 0.1-5 km/year

**Range Shift Barriers:**
1. **Habitat fragmentation:** Forest loss, urban development
2. **Geographical barriers:** Coasts, mountains, deserts
3. **Dispersal limitations:** Seed dispersal distance, juvenile mobility
4. **Microhabitat specificity:** Specialized niche requirements

**Modeling Framework:**
```typescript
interface ClimateVelocity {
  isothermSpeed: number;          // km/year isotherms moving
  terrainRoughness: number;       // 0 = flat, 1 = mountainous (slows velocity)
  habitatConnectivity: number;    // 0 = isolated, 1 = continuous
}

function calculateRangeShiftSuccess(
  species: SpeciesVulnerability,
  velocity: ClimateVelocity
): number {
  // Adjust velocity for terrain
  const effectiveVelocity = velocity.isothermSpeed * (1 - velocity.terrainRoughness * 0.5);

  // Can species keep up?
  const trackingRatio = species.rangeShiftSpeed / effectiveVelocity;

  // Habitat connectivity modifier
  const connectivityPenalty = (1 - velocity.habitatConnectivity) * 0.7;

  // Success probability
  const success = trackingRatio * (1 - connectivityPenalty);

  return Math.max(0, Math.min(1, success));
}

// Ecosystem-level failure
function calculateEcosystemCollapse(
  species: SpeciesVulnerability[],
  velocity: ClimateVelocity
): number {
  const failures = species.map(s => 1 - calculateRangeShiftSuccess(s, velocity));
  const avgFailure = failures.reduce((sum, f) => sum + f, 0) / species.length;

  // Non-linear: ecosystem collapse accelerates after 30% species loss
  if (avgFailure < 0.3) return avgFailure;
  return 0.3 + (avgFailure - 0.3) * 2.0; // 2x acceleration
}
```

## 3. Multi-Paradigm Measurement Framework

### 3.1 Traditional Ecological Knowledge (TEK) Integration

**Six Facets of TEK (Houde Framework):**
1. **Factual observations** - Species behavior, population trends, environmental changes
2. **Management systems** - Sustainable harvesting, fire regimes, water management
3. **Past and current uses** - Cultural practices, resource utilization
4. **Ethics and values** - Reciprocity, respect, interconnection
5. **Culture and identity** - Language, stories, place-based knowledge
6. **Cosmology** - Spiritual relationships with land and species

```typescript
interface TwoEyedSeeing {
  westernScience: {
    quantitative: number[];   // BII, temperature, mortality rates

    method: "parallel" | "integrated" | "complementary";
```

### 3.2 Buen Vivir and Ubuntu (Alternative Development Paradigms)

**Buen Vivir (Ecuador):**
- **Core concept:** "Good living" or "living well"
- **Subject of wellbeing:** Individual within community within environment (not isolated individual)
- **Measurement:** NOT logarithmic economic indicators (GDP)
- **Focus:** Community-environment-wellbeing interrelationship

**Ubuntu (South Africa):**
- **Core concept:** "I am because we are" - relational ontology
- **Emphasis:** Interconnection, mutual aid, communal wellbeing
- **Contrast with SDGs:** SDGs lack emphasis on reciprocity, service, interconnection

**Gross National Happiness (Bhutan):**
- **9 Domains:** Psychological wellbeing, health, education, time use, cultural diversity, good governance, community vitality, ecological diversity, living standards
- **Measurement:** Survey-based, 33 indicators across 9 domains
- **Threshold:** 66% sufficiency across domains

**Key Critique of SDGs:**
- **Western-centric:** Linear result-based management, modernist 'development'
- **Indicators as power:** Natural science method representing 'reality', not discourse
- **Missing:** Human-nature-wellbeing interrelationship
- **Lacking:** Cardinal concepts of reciprocity, interconnection, service

```typescript
function assessTransitionState(
  collapseIndicators: number,   // 0 = no collapse, 1 = total collapse
  emergenceIndicators: number   // 0 = no emergence, 1 = fully emerged
): {
  phase: "stable_old" | "collapse_only" | "transition" | "emergence_only" | "stable_new",
  tension: number  // Degree of conflict between old and new
} {
  if (emergenceIndicators < 0.1 && collapseIndicators < 0.1) {
    return { phase: "stable_old", tension: 0 };
  }

  if (collapseIndicators > 0.5 && emergenceIndicators < 0.2) {
    return { phase: "collapse_only", tension: collapseIndicators };
  }

  if (Math.abs(collapseIndicators - emergenceIndicators) < 0.3 &&
      collapseIndicators > 0.2 && emergenceIndicators > 0.2) {
    return {
      phase: "transition",
      tension: Math.min(collapseIndicators, emergenceIndicators) // Both high = high tension
    };
  }

  if (emergenceIndicators > 0.5 && collapseIndicators < 0.2) {
    return { phase: "emergence_only", tension: 0.2 };
  }

  if (emergenceIndicators > 0.8) {
    return { phase: "stable_new", tension: 0 };
  }

  return { phase: "transition", tension: 0.5 };
}
```

### 4.1 Replace Random Exogenous Shocks with Climate-Driven Functions

**Current Problem:** Random shocks (`Math.random()`) don't reflect predictable climate dynamics.

**Solution:** Climate-attributable mortality as function of:
1. **Temperature trajectory** (RCP/SSP scenarios)
2. **Infrastructure capacity** (cooling, flood protection, emergency services)
3. **Biosphere state** (ecosystem collapse amplifies human vulnerability)
4. **Extreme weather frequency** (storm intensity distribution shift)

**Unified Climate Mortality Function:**
```typescript
function calculateClimateAttributableMortality(
  state: GameState,
  rng: () => number  // Keep for stochasticity WITHIN predictable bounds
): number {
  // 1. Heat mortality (predictable)
  const heatDeaths = calculateHeatMortality(
    state.climate.wetBulbTemperature,
    state.infrastructure.coolingCapacity,
    state.population
  );

  // 2. Extreme weather mortality (fewer but stronger storms)
  const stormDeaths = calculateStormMortality(
    state.climate.globalTemperature,
    state.infrastructure.floodProtection,
    state.population.coastalExposure,
    rng  // Stochastic: which storms hit where
  );

  // 3. Biosphere collapse amplification
  const ecosystemCollapse = calculateEcosystemCollapse(
    state.ecosystem.species,
    state.climate.velocity
  );
  const bioAmplifier = 1.0 + ecosystemCollapse * 2.0; // Up to 3x mortality

  // 4. Infrastructure mismatch multiplier
  const imi = calculateIMI(state.infrastructure);

  return (heatDeaths + stormDeaths) * bioAmplifier * imi;
}
```

```typescript
  keystoneHealth: number,  // 0 = extinct, 1 = thriving
  dependentSpecies: Species[]
): number {
  const cascadeMultiplier = 2.5;  // From Joshua Tree research
```

```typescript
function checkTippingCascades(boundaries: PlanetaryBoundary[]): string[] {
  const cascades: string[] = [];

  boundaries.forEach(boundary => {
    if (boundary.transgressed && boundary.currentValue > boundary.highRiskLimit) {
      boundary.linkedBoundaries.forEach(linkedName => {
        const linked = boundaries.find(b => b.name === linkedName);
        if (linked && !linked.transgressed) {
          // Cascade triggered
          cascades.push(`${boundary.name} → ${linkedName}`);
          linked.currentValue *= 1.2; // Accelerate toward transgression
        }
      });
    }
  });

  return cascades;
}
```

## 8. Conclusion

This research provides **evidence-based, parameter-justified frameworks** for replacing random exogenous shocks with **predictable climate-driven mortality and biosphere collapse models**. The key insights:

1. **Infrastructure mismatch, not just temperature, drives mortality** - Same heat kills 3x more in regions without cooling infrastructure.

3. **Multi-paradigm measurement reveals different truths** - Western GDP may be high while Indigenous land access collapses.
4. **"Time between worlds" requires tracking both collapse AND emergence** - Regenerative indicators show what's being born while other metrics show what's dying.

**Simulation Philosophy:**
This approach maintains the project's core philosophy: **"Let the model show what it shows."** By replacing arbitrary random shocks with research-backed climate-mortality relationships, the simulation becomes a more faithful representation of scientific understanding (2024-2025) while preserving Monte Carlo stochasticity within predictable bounds.
