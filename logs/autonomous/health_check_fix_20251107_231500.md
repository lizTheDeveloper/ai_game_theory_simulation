# Autonomous Worker Health Check Fix - Nov 7, 2025 23:15

## Problem Diagnosis

Autonomous workers were failing due to two critical infrastructure bugs:

1. **Merge orchestrator Claude CLI invocation failure**
   - Used invalid `--task-file` flag (doesn't exist in Claude CLI)
   - Caused auto-remediation to fail with error code 1
   - Blocked both test failure and merge conflict remediation flows

2. **Missing test scripts in package.json**
   - `test` and `test:backend` scripts were removed
   - VM quality gates require `test:backend` to validate merges
   - Caused all merge attempts to fail with "Missing script: test:backend"

## Root Cause

**Issue 1:** Merge orchestrator script at lines 300 and 369 used:
```bash
timeout 900 claude --task-file "$REMEDIATION_TASK"
```

But `claude --help` shows no `--task-file` option. The correct approach is to pass file content as argument.

**Issue 2:** Git history shows test scripts existed previously but were removed in unknown commit. Tests still exist in `tests/` directory using Node.js native test runner.

## Fix Applied

### 1. Merge Orchestrator Fix (scripts/merge-orchestrator.sh)
```bash
# Before (WRONG):
timeout 900 claude --task-file "$REMEDIATION_TASK" >> "$LOG_FILE" 2>&1

# After (CORRECT):
timeout 900 claude "$(cat "$REMEDIATION_TASK")" >> "$LOG_FILE" 2>&1
```

Applied to both occurrences (lines 300 and 369).

### 2. Test Scripts Fix (package.json)
```json
"scripts": {
  ...
  "test": "npx tsx --test --experimental-test-coverage tests/**/*.test.ts",
  "test:backend": "npx tsx --test tests/**/*.test.ts",
  ...
}
```

Restored from git history. Uses Node.js native test runner via tsx.
