SUMMARY:
Regime shifts trigger correctly (2-4 per run) but don't affect outcomes because they only modify:
1. Outcome score adjustments (+0.3 to already-high scores)
2. Emergency response deployment (but crises may not be active)

ROOT CAUSE ANALYSIS:

1. OUTCOME SCORE ADJUSTMENTS (outcomes.ts:100-142)
   - Regime shifts add/multiply dystopia/extinction/utopia scores
   - Example: ecological-collapse adds +0.3 to extinctionScore, +0.2 to dystopiaScore
   - PROBLEM: These are absolute additions to scores that are already >0.6
   - If dystopiaScore is 0.6 and regime adds +0.3, new score is 0.9
   - Both 0.6 and 0.9 classify as "high dystopia" - no meaningful change
   - Outcome classification uses thresholds (not continuous scores)

2. EMERGENCY RESPONSE TRIGGERS (EmergencyResponsePhase.ts:375-540)
   - Regime shifts deploy emergency responses for matching crisis types
   - Example: ecological-collapse deploys climate emergency response
   - Emergency responses reduce crisis severity when completed
   - PROBLEM: Responses only help if crisis is ALREADY ACTIVE
   - If no climate crisis is active, ecological-collapse emergency does nothing
   - Timing: Regime shift at Month 80, but climate crisis might not start until Month 120

3. VARIANCE AMPLIFICATION (BifurcationLogicPhase.ts:377-519)
   - Near thresholds: amplification → 100×
   - Far from thresholds: amplification → 1×
   - PROBLEM: No system actually USES this amplification value
   - It's calculated and stored in bifState.varianceAmplification
   - But no phases read it to modify their behavior
   - Dead variable - calculated but never consumed
