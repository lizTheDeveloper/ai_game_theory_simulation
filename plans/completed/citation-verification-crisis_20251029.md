### Confirmed Fabrication Patterns

#### Pattern 1: Complete Fabrications
- **arXiv:2506.01438** - HTTP 404 (paper doesn't exist)
- **Seripally blog post** - Blog post doesn't exist
- **Anthropic shard theory** - No such publication

#### Pattern 2: Fabricated Authors
- **"Xu, J., et al." Nature 2025** → Actually unsigned editorial, ALL authors fabricated
- **"Hua, J., et al." FAccT 2024** → Actually Rivera et al., ALL 6 authors wrong

#### Pattern 3: Round Number Syndrome (100% fabrication rate)
- **"500-700 L/GPU-hour"** → Actually 0.19-0.30 L/GPU-hr (2024 Blackwell hardware)
- **"300-400 kWh/run"** → Actually MWh for full training (model-specific)
- **"30-40% AI helps"** → Appears TWICE, both anachronistic healthcare frameworks

#### Pattern 4: Phantom Publications
- **Allen 2020 (CSIS)** → Author wasn't at CSIS until 2022, publication doesn't exist
- **Zhang et al. 2021** → Real collaborating authors, publication doesn't exist

#### Pattern 5: Citation Count Inflation
- **Richardson 15,000+** → Actually 1,453 (10× exaggeration)

#### Pattern 6: Date Inflation (Discovered Phase 17)
- 5 citations dated LATER than actual publication
- Mosleh: +3 years, Richardson: +1 year, Brady: +1 year, Christiano: +1 year
- Zero citations dated earlier (asymmetric error)
- Hypothesis: Using current year when writing, not checking publication dates

## New Policies Documented

### 1. Derived Metrics Policy ✅ DOCUMENTED
**Decision:** How to handle per-hour/per-run calculations from total values

**Policy Adopted:**
- Calculate with documented assumptions (simulation needs granularity)
- Explicitly document derivation method in code comments
- Tag as `[DERIVED]` with source data and assumptions
- Add ±50% uncertainty bounds to account for derivation error
- Flag for future direct measurement validation

**Example:**
```typescript
// [DERIVED] Per-GPU-hour water from datacenter totals
// Assumption: Linear scaling, uniform GPU utilization
// Source: Li et al. (2023) - 5.5M L/day for 10,000 GPUs
// Derivation: 5.5M / (10,000 * 24) = ~23 L/GPU-hr
// Uncertainty: ±100% (geographic variance, cooling efficiency)
```

### 2. Citation Methodology Standards ✅ DOCUMENTED
**Questions addressed:**
- When is citing "all editions combined" acceptable vs. misleading?
  - **Answer:** Acceptable for cumulative citations (Rogers), misleading for edition-specific claims
- How to distinguish foundational theory citations vs. quantitative claims?
  - **Answer:** Different standards - theory can be older, quantitative must be recent
- Different standards for different citation types?
  - **Answer:** Yes - peer-reviewed > working papers > think tank > blog posts

**Added to:** `docs/RESEARCH_STANDARDS.md`

### What Worked
1. **Systematic triage** - Prioritizing by simulation impact (CRITICAL → HIGH → MEDIUM → LOW)
2. **Pattern recognition** - Round numbers, anachronisms, phantom publications
3. **Quality gates** - research-skeptic validation before implementation

3. **Citation count inflation** - 10× exaggeration (Richardson 15,000+ → 1,453)
4. **Fabricated authors are common** - Multiple papers with completely wrong author lists
5. **Silent fallbacks hide bugs** - `?? 50` masked ecology NaN bug for months
